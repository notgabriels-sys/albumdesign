PREFLIGHT Cover Art Requirements by Platform the numbers, and where each one came from

Every cover art spec, with its source

What Spotify, Apple Music, Bandcamp, Beatport, SoundCloud and Instagram ask for in release cover art, each with the page it came from and the date it was last read.

Last reviewed 2026-08. Platforms change these without much warning, so treat every number here as a starting point and check it against whatever your distributor currently demands.

Two different numbers, kept apart. "What the platform says" is the store's own published requirement, quoted from the page linked beneath it. "What this project delivers" is the file the command line tool renders for that target, which is sometimes deliberately stricter. Where a row carries no source link, nobody recorded one; that is a statement about this repository, not a claim that the number was invented.

Stores and streaming

Bandcamp

What this project delivers
3000 × 3000 px JPEG, up to 10 MB
What the platform says
1400px is the floor; Bandcamp upscales its own thumbnails from what you give it, so feed it 3000.
Source

Spotify (via distributor)

What this project delivers
3000 × 3000 px JPEG, up to 10 MB
What the platform says
Spotify itself accepts 640 to 10000 and wants the highest you have. 1600 is the floor because TuneCore enforces it; other distributors sit at 1000-1400.
Source

Apple Music

What this project delivers
3000 × 3000 px JPEG, up to 30 MB
What the platform says
Apple documents 1400 minimum and 3000 recommended, and its artist page asks for 4000. 3000 here because delivering the recommended size is the point of this target. Strictest of the DSPs: flattened RGB, no alpha, baseline (non-progressive) JPEG.
Source

Beatport

What this project delivers
3000 × 3000 px JPEG, up to 10 MB
What the platform says
Beatport publishes no minimum, only a preferred 3000x3000, so the 1400 floor here is ours: below that a 3000px render is mostly invented pixels. It can reject art tagged above 72 DPI.
Source

SoundCloud (on-platform upload)

What this project delivers
1400 × 1400 px JPEG, up to 2 MB
What the platform says
The upload form takes 800px minimum but caps the file under 2MB, so this is the target most likely to need quality walked down. Distributing THROUGH SoundCloud is a different spec, see soundcloud_distro.
Source

SoundCloud (digital distribution)

What this project delivers
3000 × 3000 px JPEG, up to 10 MB
What the platform says
SoundCloud for Artists distribution requires 3000x3000 and a perfect square, which is a different and stricter spec than the on-platform upload.
Source
